# Aakriti 3.0 – The Shape of Innovation

A fully self-developed, production-ready website for **Aakriti 3.0**, the annual technical fest of **Institute of Chemical Technology (ICT), Mumbai – Marathwada Campus, Jalna**.
(This public version is shared for **portfolio and resume purposes**.)

---

## 🚀 Tech Stack

- **React 19 + TypeScript**
- **Vite**
- **TailwindCSS**
- **Firebase (Auth + Firestore + Analytics)**
- Fully responsive design
- Dynamic event timeline + live registration portal
- Admin dashboard for event management

---

## 🌐 Live Showcase

Hosted publicly at Vercel: https://ictaakriti.vercel.app

- Fest landing experience
- Event registration system
